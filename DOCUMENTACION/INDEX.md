## 🚀 Cómo Empezar

### Setup del Proyecto
```bash
cd Back_Django_REST
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Ejecutar Tests
```bash
python manage.py test core.tests -v 2
```

### Ver Documentación
```bash
cd DOCUMENTACION/
# Ver Phase 1
cd PHASE_1/
cat PHASE_1_IMPLEMENTATION_SUMMARY.md

# Ver Phase 2

cat RESUMEN_PHASE_2_COMPLETO.md
```
