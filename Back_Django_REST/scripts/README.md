# Scripts del Backend Django

Colección de scripts para configuración, mantenimiento y testing del backend.

## Estructura

### 📁 `setup/`
Scripts de configuración inicial y despliegue.

### 📁 `maintenance/`
Scripts de mantenimiento, migraciones y utilidades.

### 📁 `testing/`
Scripts para pruebas y testing de funcionalidades específicas.

## Uso

Ejecutar scripts desde la carpeta `Back_Django_REST/`:

```bash
# Ejemplo
python scripts/maintenance/nombre_script.py
```

**Nota:** Asegúrate de tener el entorno virtual activado antes de ejecutar scripts Python.
